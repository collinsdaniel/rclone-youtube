Política de privacidade

Atualizada em 2 de novembro de 2026.

O rclone-youtube é um app de uso pessoal. Ele é usado apenas pelo dono da conta do Google, na própria máquina, para que o rclone guarde backups no Google Drive dessa mesma conta.

Dados acessados

O app acessa os arquivos do Google Drive do próprio dono, com a permissão que ele concede na tela de consentimento do Google. Esse acesso serve só para enviar, listar, conferir e apagar os arquivos de backup.

Uso, armazenamento e compartilhamento

  • Nenhum dado é enviado a servidores do app: não existe servidor. O rclone fala direto com o Google Drive.
  • O token de acesso fica só no arquivo de configuração do rclone, na máquina do dono.
  • Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.
  • O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Privacy policy (English)

rclone-youtube is a personal-use app. Only the owner of the Google account uses it, on their own computer, so that rclone can store backups in that same account's Google Drive.

It accesses the owner's own Drive files, with the permission granted on Google's consent screen, only to upload, list, verify and delete backup files. There is no app server: rclone talks directly to Google Drive. The access token stays in rclone's configuration file on the owner's computer. No data is sold, shared with third parties or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
