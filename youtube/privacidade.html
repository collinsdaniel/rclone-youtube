Política de privacidade

Atualizada em 6 de novembro de 2026.

O YouTube Sophia Publicar é um app de uso pessoal. Ele é usado apenas pelo dono da conta do Google, na própria máquina, para enviar os vídeos do canal dele ao YouTube.

Dados acessados

O app acessa o canal do YouTube do próprio dono, com a permissão que ele concede na tela de consentimento do Google. Esse acesso serve só para enviar vídeos como privados, definir a thumbnail, incluir os vídeos nas playlists do canal e ler o nome do canal e das playlists. O app não apaga vídeos nem lê dados de outros canais.

Uso, armazenamento e compartilhamento

  • Nenhum dado é enviado a servidores do app: não existe servidor. O app fala direto com o YouTube.
  • O token de acesso fica só num arquivo na máquina do dono.
  • Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.
  • O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Privacy policy (English)

YouTube Sophia Publicar is a personal-use app. Only the owner of the Google account uses it, on their own computer, to upload their channel's videos to YouTube.

It accesses the owner's own YouTube channel, with the permission granted on Google's consent screen, only to upload videos as private, set their thumbnail, add them to the channel's playlists and read the channel and playlist names. It does not delete videos or read other channels' data. There is no app server: the app talks directly to YouTube. The access token stays in a file on the owner's computer. No data is sold, shared with third parties or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
